# unfurl-foundry-substrate

Use `unfurl-foundry-substrate` when a product needs shared AI-agent shapes and
ports without taking on concrete model SDKs, vector databases, credential
stores, or servers. It is the AI-side substrate layer for agents, tools, prompts,
RAG, model providers, and the minimal embedded agent/harness runtime.

`unfurl-foundry-substrate` contains coordinated Java AI/agent substrate artifacts for Foundry runtime products.
